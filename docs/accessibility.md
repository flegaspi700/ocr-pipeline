# Accessibility

folders, see results). The checklists and how to test are in the standard's
`accessibility.md`; this file records which apply and the results.

**Applies:** Apps and websites (WCAG 2.2 AA, where the UI library allows)
**Target:** NFR3 in `requirements.md`
